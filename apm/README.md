# APM (Agent Package Manager)

Notes about [microsoft/apm](https://github.com/microsoft/apm), a package
manager for AI agent primitives (instructions, agents, skills, prompts,
hooks/commands, MCP servers). APM lets a package author write a primitive
once and have it compiled to the native format of many coding-agent
harnesses (GitHub Copilot, Claude, Cursor, Windsurf, Kiro, OpenCode, Codex,
Gemini CLI, Grok Build, Antigravity).

Use this folder for anything about authoring, compiling, packaging, or
distributing APM primitives — frontmatter schemas, per-target compilation
behavior, and the tradeoffs between primitive types.
